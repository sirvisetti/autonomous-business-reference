Optional binding

Minimal HTTP reference

ABCS business semantics are transport-neutral. This project demonstrates one optional HTTP binding so adopters can experiment with a familiar interface without making HTTP normative.

Discover

GET /capabilities

Describe

GET /capabilities/procurement.purchase-order.submit

Invoke

POST /capabilities
Content-Type: application/json

{
  "abcs": "0.2",
  "capability": "procurement.purchase-order.submit",
  "requestId": "demo-001",
  "payload": { ...canonical Purchase Order... }
}
